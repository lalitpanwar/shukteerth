# SEO Strategy

## Technical foundation

- Use Next.js metadata for every route.
- Use descriptive titles, unique meta descriptions, canonical URLs, and Open Graph images.
- Publish `robots.txt` and `sitemap.xml` before launch.
- Validate semantic headings, landmarks, structured data, and Core Web Vitals.

## Content clusters

- Shri Shukdev Ashram and brand terms.
- Ashram visits and spiritual retreats in Uttarakhand.
- Teachings, satsang, meditation, and seva.
- Shukteerth and lineage information.

## Structured data

Evaluate `Organization`, `Place`, `Event`, `FAQPage`, and `BreadcrumbList` schema against verified content before publishing.
