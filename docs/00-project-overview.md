# Project Overview

## Purpose

Shri Shukdev Ashram is a calm, accessible digital home for spiritual learning, ashram visits, seva, and donations.

## Project goals

- Help visitors understand the Ashram and its living tradition.
- Make an in-person visit easy to plan.
- Present teachings with clarity and reverence.
- Support seva and donations with trust and transparency.

## Technical baseline

- Next.js App Router
- React Server Components by default
- Tailwind CSS v4 with component-scoped CSS Modules where appropriate
- Lucide icons

## Delivery principles

- Accessibility, performance, and SEO are baseline requirements.
- Content, navigation, and repeatable copy belong in configuration.
- Pages compose reusable sections; they do not contain complex UI logic.
