# Brand Guidelines

## Brand character

Quiet, grounded, generous, timeless, and welcoming. The visual language should feel devotional without becoming ornamental or inaccessible.

## Voice

- Use clear, warm, plain language.
- Lead with invitation rather than instruction.
- Use Sanskrit sparingly and always provide useful context.
- Avoid urgency, spiritual claims, and inaccessible insider language.

## Core palette

| Token | Value | Use |
| --- | --- | --- |
| Ink | `#20291E` | Primary text |
| Moss | `#263726` | Deep surfaces |
| Paper | `#F4F0E6` | Page backgrounds |
| Cream | `#FBF6EB` | Text on dark surfaces |
| Saffron | `#D9A751` | Calls to action and accents |

## Tailwind brand utilities

Use these semantic utility classes for brand color styling:

| Utility | Purpose |
| --- | --- |
| `bg-brand-saffron` | Saffron backgrounds |
| `bg-brand-maroon` | Maroon backgrounds |
| `bg-brand-ivory` | Ivory backgrounds |
| `bg-brand-sand` | Sand backgrounds |
| `text-brand-brown` | Brown text |
| `text-brand-gold` | Gold text |
| `border-brand-border` | Brand border color |

## Typography

- Use a highly legible serif for editorial headings.
- Use a neutral sans-serif for navigation, forms, and body copy.
- Maintain clear contrast, restrained letter spacing, and a readable line length.
